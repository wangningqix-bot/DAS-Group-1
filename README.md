# DAS Group 1 – Household Size Analysis

## Project Overview

This project analyses household survey data from the **Family Income and Expenditure Survey (FIES)** in the Philippines.

The aim of the analysis is to investigate **which household-related variables influence the number of people living in a household**.

The analysis is carried out using **Generalised Linear Models (GLM)** in R.

---

## Dataset

The dataset contains household-level information including:

- household income
- food expenditure
- age and sex of the household head
- house characteristics (floor area, number of bedrooms, house age)
- electricity access
- region

The response variable is:

**Total.Number.of.Family.members**

which represents the number of people living in the household.

---

## Analysis

The analysis includes:

1. Exploratory Data Analysis (EDA)
2. GLM modelling to investigate factors influencing household size
3. Interpretation of significant variables

All analysis is implemented in **R** and documented in:
